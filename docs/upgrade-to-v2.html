Still on Agent 1.x?

If some of your hosts are still running 1.x, it will continue to send host metrics, but it gets no new features or fixes.

Upgrade to Agent 2.x

Zero-code tracing

eBPF RED metrics and spans from the kernel. No SDK, no code change, no restart.

Service discovery

Apps and containers show up automatically. Turn tracing on per service from the UI.

Managed configuration

Collector config syncs from the console. No hand-edited YAML per host.

Docker awareness

Container metrics and logs on Linux are collected automatically when Docker is present.

Follow the steps below to upgrade

Grab the install command

Head to Settings → Agents in the console and copy the Agent 2.x install command for your host.

About two minutes per host, no reboot required.

Enable APM, databases, and logs

The KloudMate Agent V2 was rebuilt to remove the manual setup work entirely. It discovers your services, collects host metrics and logs, and runs eBPF monitoring automatically the moment you install it — with zero code changes. Of course, there are also SDKs for deeper granularity and insights.

APM, database, and log monitoring are now wizards and toggles, instead of hand-written config files.

That's all

You'll now get APM, traces, and logs — you can even turn on process monitoring too.
